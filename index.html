Detailed Explanations & Structural Analysis

In-depth technical breakdown of correct choices

Q01 Correct: B
Giving AI a job fundamentally shifts human effort from generating intermediate steps to defining the expected outcome and rigorously verifying the resulting deliverable[cite: 1]. Accountability stays with the human supervisor throughout[cite: 1].
Q02 Correct: B
Prescribing strict step-by-step recipes limits execution to the user's manual approach. Delegating the outcome allows the system to determine optimal paths while leaving the human to evaluate results against defined acceptance criteria.
Q03 Correct: B
A standard Delegation Brief comprises six foundational elements: Outcome, Context, Constraints, Authority, Deliverable, and Verification.
Q04 Correct: B
The Authority section specifies decision-making parameters. It delineates autonomous actions from those requiring explicit user approval before proceeding.
Q05 Correct: A
An answer provides conversational chat responses, whereas a deliverable yields a complete, structured artifact (such as a formal document or structured table) ready for external use.
Q06 Correct: C
The Delegation Loop consists of Define, Delegate, Observe, Intervene, Verify, and Accept[cite: 1]. The Verify step requires evaluating output against brief specifications prior to acceptance[cite: 1].
Q07 Correct: B
Ground-truth prompts require restricting output to provided sources and instructing the model to mark missing items explicitly (e.g., "not in source") to eliminate ungrounded synthesis.
Q08 Correct: B
The Plan-First protocol requires the agent to present its proposed execution steps and wait for explicit human go-ahead before executing tasks.
Q09 Correct: B
In project settings, permanent rules belong in Standing Instructions, while static reference materials are stored as persistent Knowledge files.
Q10 Correct: B
When execution drifts off-course without breaking ground rules, the targeted intervention move is "Redirect Direction".
Q11 Correct: B
Portability means a brief focuses on fundamental task parameters rather than platform-specific UI controls, running across multiple LLMs without modification.
Q12 Correct: B
The Verification Opened framework follows four structured sub-steps: Identify, Trace, Challenge, and Decide.
Q13 Correct: A
Handling sensitive data requires sanitizing private identifiers and utilizing temporary or incognito sessions to prevent persistent indexing.
Q14 Correct: B
Formatting errors or hallucinations into clean deliverables can create operational risks, as professional presentation often masks unverified underlying data.
Q15 Correct: B
Automating execution does not transfer legal or operational liability; final oversight and decision-making remain with the human delegator[cite: 1].
Q16 Correct: B
When a task exceeds base capacity, the "Escalate Capability" move switches to advanced reasoning modes or stronger model architectures.
Q17 Correct: B
Persistent Knowledge files act as primary context sources for all subsequent executions within a designated project workspace.
Q18 Correct: B
Vague constraints allow models to make arbitrary decisions, potentially violating operational limits, formatting needs, or privacy controls.
Q19 Correct: A
Validating web research requires verifying source dates, as search tools can surface outdated or hallucinated link previews.
Q20 Correct: C
The final phase of verification is "Decide," leading to Accept, Correct, Investigate, or Reject.
Q21 Correct: B
If model performance remains sub-standard after targeted interventions, the final recovery step is "Take Job Back" for manual execution.
Q22 Correct: A
A Delegation Record acts as an audit trail documenting the original brief, operational logs, verification steps, and final human approval.
Q23 Correct: B
Explicit Authority parameters establish decision boundaries, preventing unauthorized actions during autonomous execution.
Q24 Correct: B

Q25 Correct: A
The "Need First, Then Tool" methodology enables platform features (such as live search or code interpreters) only when explicitly required by task constraints.
Q26 Correct: B
Parametric Memory refers to static internal knowledge trained into model weights, bound by training cutoffs.
Q27 Correct: A

Q28 Correct: B
To prevent recurring errors, lessons learned during execution should be codified into project Standing Instructions or reusable brief templates.
Q29 Correct: B
